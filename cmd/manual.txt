namo reference
==============

namo generates memorable, sortable names of the form:

    [prefix-]stamp-slug

    debug-output-260711154501-star-studded-booze-cruise
    |            |            |
    prefix       stamp        slug

- prefix: optional descriptive label passed with -p/--prefix or
          --raw-prefix.
- stamp:  timestamp, yymmddhhmmss by default, providing a local-time
          sort key.
- slug:   memorable random words from hotdiva2000, for human
          identification.

Generated names and other successful command output, including help,
go to stdout; errors go to stderr. Without --raw-prefix or a custom
--stamp, generated output contains one name per line, making uses such
as this safe:

    filename=".sandbox/$(namo -p debug-output).log"

Flags
-----

-p, --prefix TEXT    Strictly normalized descriptive prefix joined
                     with a hyphen.
    --raw-prefix TEXT
                     Trusted-input-only unsafe prefix passthrough.
-n, --count N        Generate N names (default 1). The whole batch
                     shares one timestamp; slugs are unique within
                     the batch.
-s, --size SIZE      Slug length: short, standard (default), or long.
                       short     modifier-noun only, e.g. booze-cruise
                       standard  occasional extra words
                       long      always adds extra prefix and suffix
                                 words
    --stamp LAYOUT   Custom strftime-style timestamp layout.
                     Default: %y%m%d%H%M%S
    --short-stamp    HHMM timestamp (same as --stamp %H%M), for
                     ephemeral names you only need to tell apart
                     within a day.
    --no-stamp       Omit the timestamp entirely: just the slug.

--prefix accepts ASCII letters and digits as content, lowercases
letters, replaces each run of other characters with one dash, and
removes edge dashes. It errors if no ASCII letters or digits remain.
--raw-prefix is a trusted-input-only unsafe escape hatch. For a
non-empty raw prefix, namo preserves the supplied bytes and then adds
one joining hyphen; a trailing dash can therefore produce doubled
dashes. An empty raw prefix behaves as no prefix. Raw line breaks,
control bytes, and path separators are preserved, so they can bypass
the normal one-name-per-line, command-substitution, terminal, and path
safety guarantees. --prefix and --raw-prefix are mutually exclusive.

For example:

    namo -p "Debug Output / API"
    # debug-output-api-260711154501-star-studded-booze-cruise

    namo --raw-prefix "Build_42"
    # Build_42-260711154501-star-studded-booze-cruise

--stamp, --short-stamp, and --no-stamp are mutually exclusive.

Stamp layout verbs
------------------

    %Y  four-digit year   2026        %H  hour (00-23)
    %y  two-digit year    26          %M  minute
    %m  month             07          %S  second
    %d  day               11          %%  literal percent sign

Any other verb is an error. Literal characters pass through
unchanged, so layouts like %Y-%m-%d work as expected.

Recipes
-------

Sortable log or scratch file:

    log=".sandbox/$(namo -p fish-profile).log"

Family of output files sharing one run prefix:

    prefix="$(namo)"
    response="out/${prefix}-response.md"
    meta="out/${prefix}-meta.json"

Branch or session handle (no timestamp):

    git switch -c "spike/$(namo --no-stamp -s short)"

Ephemeral name, only needs to be unique today:

    namo --short-stamp

Batch of seed identifiers:

    namo -n 25 --no-stamp

Exit codes
----------

    0  success
    1  any error (bad flag, invalid layout, generation failure)
